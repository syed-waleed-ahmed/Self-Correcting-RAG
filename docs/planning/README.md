# Planning documents

These documents started as the Phase 0 audit and plan for turning SCRAG into
a hosted platform that runs entirely on free tiers. They were written while the
project was being built, and they stay public for transparency: what was
measured, what was decided and why, what is deferred, and how cost is kept at
zero. Each is dated and is updated as phases land. The decisions that were
implemented are also recorded as ADRs in [../decisions/](../decisions/).

| Document | Purpose |
| --- | --- |
| [CURRENT_STATE_AUDIT.md](CURRENT_STATE_AUDIT.md) | What exists, baseline quality results, defects found, what Phase 1 fixed |
| [TARGET_ARCHITECTURE.md](TARGET_ARCHITECTURE.md) | Proposed architecture, key decisions (D1-D9), LLM budget model, scaling targets |
| [FREE_TIER_SERVICE_MATRIX.md](FREE_TIER_SERVICE_MATRIX.md) | Verified free-tier limits per service, with sources and dates |
| [IMPLEMENTATION_ROADMAP.md](IMPLEMENTATION_ROADMAP.md) | Phases, acceptance criteria, status, open decisions |
| [RISK_REGISTER.md](RISK_REGISTER.md) | Platform, cost, quality, security and engineering risks with mitigations |
| [DEPLOYMENT_PLAN.md](DEPLOYMENT_PLAN.md) | Current and target deployment, manual steps, smoke tests, evidence log |
| [COST_ZERO_VERIFICATION.md](COST_ZERO_VERIFICATION.md) | Billing exposure per service and the monthly re-verification checklist |
